# API verification matrix

Every operation in the live Swagger document (77), verified 2026-10-07 and **re-verified 2026-10-08** after the backend update against
`https://earlystep22.runasp.net/api/` with the demo accounts (no Teacher account). Status codes and
shapes only — no personal data, no credentials. Shapes: `api/LIVE_CONTRACTS.md`.

**How:** the app's own API functions in `npm run test:live:read` / `npm run test:live:write`
(disposable `E2E Test …` records, deleted and verified in `afterAll`), plus Python scripts outside
the repo for icon uploads, extra question types, chat and plan add/remove. **Auth tested:** an
anonymous sweep of all 75 operations (status codes only, 10-07) — 67 of 69 protected operations returned
401; the remaining two return 401 since 10-08; authenticated cross-role calls return 403.
